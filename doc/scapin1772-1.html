GENERAL HEADQUARTERS
SUPREME COMMANDER FOR THE ALLIED POWERS

AG 311.23 (10 Feb 48) CCS

(SCAPIN - 1772/1)

APO 500

10 February 1948

MEMORANDUM FOR :JAPANESE GOVERNMENT.
SUBJECT :Registering of Code Addresses.

1. Reference is made to File AG 311.23 (10 Sep 47)CCS SCAPIN 1772, dated 10 September 1947, subject as above.

2. Effective 15 February 1943, paragraph 3 of reference memorandum is rescinded and the following substituted in lieu thereof:

Code addresses will be registered for a period of one (1) year. The Ministry of Communications may assess a service charge, payable in advance in Japanese yen, of ¥120 for each code address registered for each one (1) year period. All registrations of code addresses not renewed within thirty (30) days after the end of the period for which they are registered will automatically expire.

3. Existing code addresses are not affected until such time as each individual code address becomes eligible for renewal, at which time the revised service charge will be collected.

4. Direct communication between Civil Communications or other Staff Sections of General Headquarters, Supreme Commander for the Allied Powers and the Ministry of Communications, within the scope of this memorandum is authorized.

FOR THE SUPREME COMMANDER:

R.M. LEVY,
Colonel, AGD,
Adjutant General.
