GENERAL HEADQUARTERS
SUPREME COMMANDER FOR THE ALLIED POWERS

AG 387.6 (3 Dec 47) REP

(SCAPIN - 1751/6)

APO 500

3 December 1947

MEMORANDUM FOR :THE JAPANESE GOVERNMENT.
THROUGH :Central Liaison Office, Tokyo.
SUBJECT :Responsibility of the Japans Government for the Packaging, Transfer and Delivery of Equipment and Records Allocated to Claimant Nations Under the Reparations Program.

1. Reference is memorandum for the Japanese Government from General Headquarters, Supreme Commander for the Allied Powers, file AG 387.6 (22 Jul 47)REP, (SCAPIN 1751), dated 22 July 1947, subject as above.

2. Changes in Annex 6, reference 1, as requested by memorandum for General Headquarters, Supreme Commander for the Allied Powers, from Japanese Government, file CLO No. 8427 (RSE), dated 27 October 1947, subject: Changes in Instructions for Construction of Exterior Wooden Containers, are approved as shown in Annex 1. Any change from that originally requested is underscored. Paragraphs indicated in Annex 1 refer to identical paragraph of Annex 6, reference 1.

3. In addition to the changes authorized by paragraph 2, the following changes in reference 1 are directed. References cited refer to paragraph numbers of indicated annexes of reference 1.

4. a. Reference is Inclosure 1, Annex 3. The original Inclosure 1 is replaced by Annex 2 of this directive.

b. Reference is paragraph II 1d, Annex 7. Add to paragraph II 1d the following: "complete inventory number of machine."

c. Reference is paragraph II 2, Annex 7, Arrangement: The original Inclosure 1 is replaced by Annex 3 of this directive. The changes have been the addition of a position-code-number directly under the description of contents and complete machine inventory code number to the left of the packing list.

d. Reference is paragraph II 3e, Annex 7, Package Number. Under paragraph II 3e insert paragraph (4 1/2) reading as follows: "In the case of pooled items, the package number will begin with the number '1' for each allocation notice number and will increase consecutively to cover all equipment allocated under that allocation notice number."

e. Reference is paragraph II 3, Annex 7, Detail and Instructions of Stenciling. Under paragraph II 3, insert paragraph i, Position Code Number, reading as follows: "This number will appear directly below the description of contents. The number, different for each machine allocated, will be used as a ready means for keying the packaged machine with the original International Business Machine lists indicating respective shares allocated to recipient nations. If item is packaged in more than one (1) container, position code number will appear on all packages containing the component parts."

f. Reference is paragraph III 2(a)(1), Annex 7. The original Inclosure 2 is replaced by Annex 4 of this directive. The changes have been the addition of a position-code-number and the substitution of machine inventory number for plant code symbol.

g. Reference is paragraph III 2a(5), Annex 7. Delete paragraph III 2a(5), and substitute the following:

(5) Complete inventory number of item packaged. If item is packaged in more than one (1) container, inventory number will appear on all packing lists covering component parts.

h. Reference is paragraph III 2a, Annex 7. Under paragraph III 2a, insert paragraph (8 1/2), Position Code Number. If item is packaged in more than one (1) container, position code number will appear on all packing lists covering component parts.

i. Reference is paragraph III 2a(9), Annex 7. Delete paragraph III 2a(9), and substitute the following:

(9) List of contents, including:

(a) Quantity.

(b) Description of packaged item recorded in the following manner:

1. Name of item packaged. If item packaged is a part of a major assembly, indicate the name of the major assembly of which it is a part. For example, the bed of a planer which is being packaged separate from major item would be "Bed, for planer."

2. Complete or less certain components. If the item packaged is a major item from which a component part has been removed, for example, the planer from which bed was removed (reference paragraph III 2a(9)(b)1, above), the entry would be "Planer, less bed." If major item is packaged complete in one container, the entry of "Complete" should be made on the packing list.

4. Reference is Annex 1. Lumber sizes referred to are nominal sizes and not actual sizes. Accordingly, the practice of vesting lumber by re-cutting to actual size will cease. However, in no case will a board of actual thickness less than 0.6 sun be permitted.

FOR THE SUPREME COMMANDER:

R.M. LEVY,
Colonel, AGD,
Adjutant General.

4 Annexes

2. Inclosure to Allocation Notice for Pooled Items

3. Arrangement of Containe Markings

4. Packing List
